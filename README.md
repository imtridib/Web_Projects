# Web Projects

A collection of front-end practice work and related design assets. The repository includes HTML/CSS implementation files, image assets, and design exports.

## Contents

- `index.html` — main page entry point.
- `style.css` — page styling.
- `assets/` — images and technology/social icons used by the page.
- `Designs/` — related design exports, including Figma and PDF/image references.

## Run locally

1. Clone or download the repository.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Keep the relative folder structure intact so images and styles load correctly.

The current project is static and has no configured package installation or build step.

## Purpose

This repository is a web development learning/portfolio archive. It is separate from the AI/ML projects highlighted on the profile.
